# External dependencies

One of the goals of this project is to use as few dependencies as sensible. We don't want any build tooling for the UI.

This is the current list of dependencies included in this repo:

- [HTM (with preact)](https://github.com/developit/htm/blob/master/README.md)
- [Preact Signals](https://github.com/preactjs/signals)
- [Sortable](https://github.com/SortableJS/Sortable)
